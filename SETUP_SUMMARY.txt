================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Python not found"
SOLUTION: Install Python 3.7+ from python.org
          Windows: Check "Add Python to PATH"

PROBLEM: "colorama module not found"
SOLUTION: pip install colorama
          OR: pip install -r requirements.txt

PROBLEM: "Permission denied" (Linux)
SOLUTION: chmod +x metasploit_exploit_generator.py
          OR: python3 metasploit_exploit_generator.py --help

PROBLEM: "msfvenom not found"
SOLUTION: sudo apt install metasploit-framework (Kali)
          OR: Download from metasploit.com (Windows)

PROBLEM: Listener connection refused
SOLUTION: 1. Verify LHOST is your IP (not localhost)
          2. Check firewall rules
          3. Use 0.0.0.0 to listen on all interfaces
          4. Verify payload LHOST matches listener
